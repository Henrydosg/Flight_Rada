# Sources and attribution

**Flight_Rada** is Henrydosg's Waveshare LCD-7 port of [esp32flight](https://github.com/theqkash/esp32flight) by **Łukasz Nowak (@theqkash)** and its contributors. It starts at [upstream commit b62a100](https://github.com/theqkash/esp32flight/commit/b62a100a4ec967b296a0426ac895b3e7aa5ffd31). The original [MIT license and copyright notice](LICENSE), Git history and in-file notices are retained. Upstream supplied the radar, UI, web panel, Android port and board drivers. This fork adapts the N8R8 display profile, firmware checks, interface and manual location entry.
